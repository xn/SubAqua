# the garbo fork → SubAqua: transferable ideas

**What the garbo fork actually is.** `the fork checkout` is a fork of garbage-collector
(remotes: `Shiverwarp/garbage-collector`, `Ignose/garbage-collector`; branch `a sea-focused branch`)
with a second farming strategy bolted on: `FarmingMethod.THE_CORAL_CORRAL`
(`packages/garbo/src/config.ts:270-286`, `packages/garbo/src/farmingStrategy.ts:115-177`).
It farms **sea cows in The Coral Corral** all day for meat, banishing the two trash draws
(sea cowboy, Mer-kin rustler) and requiring a tamed seahorse + the sea cow Fishy fact as
preconditions (`index.ts:151-161`). It never touches Mer-kin quest content, the temple
bosses, the outpost, pearls-as-quest-items, or the corral _as a quest_ — so the overlap
with SubAqua is exactly: **the corral roster, breathing, Fishy upkeep, banish economy,
and underwater combat-macro mechanics.** Everything else in the garbo fork is meat farming.

All the garbo fork paths below are relative to `the fork checkout/packages/garbo/src/`.
All SubAqua paths are relative to the repo root at HEAD `0ccf0d7`.
